# 管理员操作清单

> 面向团队管理员：一次性准备工具仓库、记忆仓库和成员接入方式。本文使用占位符示例，适用于 Gitea / GitHub / GitLab / Forgejo 等 Git 服务。

## 目标架构

```text
agent-team-memory  工具仓库：CLI / Web UI / MCP / 模板 / 文档
team-memory        记忆仓库：Markdown 记忆文件，Git 管理

成员机器
  ├── 安装 agent-team-memory
  ├── clone team-memory
  └── load --global 桥接 Claude Code / Codex / Hermes / Trae
```

## 准备信息

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `<TOOL_REPO>` | 工具仓库地址 | `https://git.example.com/org/agent-team-memory.git` |
| `<MEMORY_REPO>` | 记忆仓库地址 | `https://git.example.com/org/team-memory.git` |
| `<TEAM_NAME>` | 团队显示名 | `Platform Team` |
| `<ADMIN>` | 管理员英文短名 | `alice` |
| `<MEM_ROOT>` | 本机记忆仓库路径 | `~/team-memory` |

## 1. 创建两个仓库

在你的 Git 服务上创建：

1. `agent-team-memory`：存放本工具源码。
2. `team-memory`：存放团队记忆数据。建议设为私有仓库。

`team-memory` 不需要预置复杂内容，可以由工具初始化。

## 2. 安装工具

```bash
git clone <TOOL_REPO>
cd agent-team-memory
python -m pip install -e .

# 如需 MCP Server
python -m pip install -e ".[mcp]"
```

## 3. 初始化记忆仓库

```bash
team-memory init -p <MEM_ROOT> -n "<TEAM_NAME>" -a <ADMIN>
cd <MEM_ROOT>
git remote add origin <MEMORY_REPO>
git add .
git commit -m "init team memory"
git push -u origin HEAD
```

初始化后，记忆仓库会包含：

```text
memory/project/
memory/code/
memory/decisions/
memory/errors/
memory/skills/
inbox/
rules/
```

## 4. 配置成员接入

把以下信息发给团队成员：

```text
工具仓库：<TOOL_REPO>
记忆仓库：<MEMORY_REPO>
默认记忆路径：~/team-memory
每个人需要一个唯一英文短名，例如 alice / bob / zhang3
```

成员可以执行：

```bash
python scripts/onboard.py <MEMORY_REPO> <author>
```

该脚本会：

- clone 或更新 `~/team-memory`
- 安装 `agent-team-memory`
- 写入 `.env`
- 执行 `team-memory load --global`
- 运行 `doctor` 和 `check-bridges`

## 5. 可选：启动共享 Web UI

管理员可以在一台服务器上启动 Web UI，供团队浏览。

```bash
export TEAM_MEMORY_ROOT=/srv/team-memory
export WEB_HOST=0.0.0.0
export WEB_PORT=8765
python -m team_memory web -p "$TEAM_MEMORY_ROOT" --no-browser
```

也可以参考 `scripts/team-memory-web.service` 配置 systemd。

## 6. 可选：配置 MCP

MCP 让 AI 工具在对话中动态读取和提交候选记忆。

```bash
python -m pip install -e ".[mcp]"
TEAM_MEMORY_ROOT=<MEM_ROOT> python -m team_memory.mcp_server
```

各工具配置见 [MCP接入.md](MCP接入.md)。

## 7. 日常治理规则

- 正式记忆进入 `memory/`，候选记忆进入 `inbox/`。
- AI 可以 `propose`，核心记忆建议由人 `approve`。
- `project` / `decision` 类型变更建议走 review。
- 过时记忆不要删除，用 `status: superseded` 和 `superseded_by` 追踪。
- secrets、token、密码不要写进任何记忆文件。
- sync 前先 commit，保持 Git 历史可审计。

## 8. 验收清单

- [ ] `team-memory init` 能生成记忆仓库。
- [ ] `team-memory capture "test" -t decision -p <MEM_ROOT>` 能写入记忆。
- [ ] `team-memory save "test" -t skill -p <MEM_ROOT> --note "..."` 能写入并 commit。
- [ ] `team-memory list` 能列出记忆。
- [ ] `team-memory web` 能打开 Web UI。
- [ ] `team-memory load --global` 能安装全局桥接。
- [ ] `team-memory doctor` 无错误。
- [ ] 新成员可用 `scripts/onboard.py` 完成接入。
