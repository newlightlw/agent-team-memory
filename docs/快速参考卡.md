# 快速参考卡

## 管理员初始化

```bash
git clone <TOOL_REPO>
cd agent-team-memory
python -m pip install -e .

team-memory init -p ~/team-memory -n "<TEAM_NAME>" -a <author>
cd ~/team-memory
git remote add origin <MEMORY_REPO>
git add .
git commit -m "init team memory"
git push -u origin HEAD
```

## 成员接入

```bash
git clone <TOOL_REPO>
cd agent-team-memory
python scripts/onboard.py <MEMORY_REPO> <author>
```

`<author>` 必须是英文短名，用于生成记忆 id，例如 `alice`、`bob`、`zhang3`。

## 常用命令

```bash
# 写正式记忆
team-memory capture "标题" -t decision -p ~/team-memory --via codex

# 写正式记忆并 commit
team-memory save "标题" -t skill -p ~/team-memory --via claude --note "..."

# AI/未验证经验先进候选区
team-memory propose "标题" -t error -p ~/team-memory --via claude

# 审核候选
team-memory review -p ~/team-memory
team-memory approve <memory-id> -p ~/team-memory
team-memory decline <memory-id> -p ~/team-memory --reason "原因"

# 查看和搜索
team-memory list -p ~/team-memory
team-memory show <memory-id> -p ~/team-memory

# 同步远端
team-memory sync -p ~/team-memory

# Web UI
team-memory web -p ~/team-memory

# 健康检查
team-memory doctor -p ~/team-memory
team-memory validate -p ~/team-memory
```

## 五类记忆

| 类型 | 目录 | 用途 |
| --- | --- | --- |
| `project` | `memory/project/` | 项目目标、范围、架构、约束 |
| `code` | `memory/code/` | 代码结构、入口、模块关系 |
| `decision` | `memory/decisions/` | 技术选型和架构决策 |
| `error` | `memory/errors/` | 错误、根因、解决方案 |
| `skill` | `memory/skills/` | 可复用流程和操作手册 |

## MCP

```bash
python -m pip install -e ".[mcp]"
TEAM_MEMORY_ROOT=~/team-memory python -m team_memory.mcp_server
```

```text
search_memory

list_memories

```

## 铁律

- Git 仓库里的 Markdown 是唯一真相。
- AI 可以提交候选，正式记忆需要审核。
- 新写入通常下个会话生效。
- 过时记忆废弃不删除。
- secrets 不入库。
